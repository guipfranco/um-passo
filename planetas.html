Três caminhos para as peças girarem. Toque em ver o truque para ver como cada um funciona por dentro.

1Bola de mentira

Uma imagem plana do planeta desliza atrás de um círculo. Uma sombra parada por cima dá o volume.

só CSS
com curvatura
(canvas)
imagem plana deslizando janela redonda

A imagem inteira passa por trás (apagada, em volta). O círculo só deixa ver um pedaço. Na versão só CSS a imagem não encurva na borda; a versão com curvatura corrige isso.

Peso
uma imagem por peça

2Giro gravado

O giro é filmado uma vez, quadro a quadro. O jogo só passa o filme, como um gif.

Quadros:

Este é o filme inteiro. O jogo mostra um quadro de cada vez. Giro lento com poucos quadros engasga; com muitos, o arquivo cresce.

Peso
cresce com os quadros
Serve para
qualquer forma: asteroide, cometa, meteorito
Luz
fica gravada, não muda depois
No código

33D ao vivo

O jogo desenha o objeto em 3D a cada quadro. Arraste as peças para girar.

asteroide
planeta

Por dentro: o asteroide é uma malha de triângulos; o planeta é uma imagem enrolada na bola (as linhas são os meridianos e paralelos da imagem).

Peso
a biblioteca three.js, uns 170 KB, uma vez só
Serve para
tudo, e cada peça pode nascer diferente
Luz
de verdade, muda ao vivo
No código
refazer o desenho do tabuleiro

Aqui é um motor caseiro e simplificado. Com three.js fica mais liso, com brilho e contorno de verdade.

Minha aposta

Começar com 1 + 2: o 1 para o que é redondo, o 2 para o que é torto. Dá quase todo o efeito sem reescrever o tabuleiro. O 3 vale se a luz ao vivo e a junção em 3D virarem parte da graça do jogo.
